# ULLE Social Automation

Дневна рутина, която сама прави пост за ULLE и го подготвя за одобрение:

```
plan → ulle-backgrounds промпт → OpenAI рендер → HTML текст овърлей → одобрение → публикуване
```

- **Текст върху картинката:** HTML темплейт + системния **Chrome headless** → пиксел‑перфектна кирилица, точно в `text_zone` от скила. Моделът НЕ пише текста (за да няма счупена кирилица).
- **Фон:** OpenAI `gpt-image-1` с референтна снимка на тениската (identity lock). Без ключ → **placeholder** фон, за да тестваш целия поток.
- **Публикуване:** по подразбиране **с одобрение** — нищо не се качва само. Ти преглеждаш и пускаш.
- **Zero dependencies:** само Python stdlib + Chrome. Нищо за `pip install`.

## Настройка (еднократно)

1. **Ключ за рендер:**
   ```bash
   cp .env.example .env
   # отвори .env и сложи OPENAI_API_KEY=...
   ```
2. **(по избор) Meta токени** за авто‑качване при одобрение — виж `.env.example`.
3. **(по избор) Шрифтове:** сложи `Heading.ttf` и `Body.ttf` в `assets/fonts/` за брандов шрифт; иначе се ползва системен.
4. **Инсталирай дневната рутина:**
   ```bash
   bash install_cron.sh
   ```
   Часът се чете от `config.json` → `schedule.time` (по подразбиране 10:00, Europe/Sofia).

## Ръчно ползване

```bash
# Генерирай днешния пост (стейджва го за одобрение):
python3 -m pipeline.run_daily

# Виж какво чака:
python3 -m pipeline.approve --list

# Одобри и публикувай (или подготви за ръчно качване):
python3 -m pipeline.approve 2026-09-05-01
```

Готовите файлове са в `state/queue/<id>/`:
- `post.png` — финалният пост (фон + текст)
- `background.png` — само фонът
- `bg.json` — ulle-backgrounds промптът (валидиран)
- `caption.txt` — описание + хаштагове
- `plan.json` — целият план на поста

След одобрение постът се мести в `state/published/<id>/`. Без Meta токени готовият пост се копира в `state/approved/<id>/` за ръчно качване.

## Конфигурация — `config.json`

- `schedule.time`, `posts_per_day` — кога и колко поста на ден
- `platforms` — `instagram`, `facebook`
- `products` — продукти с референтна снимка, щампа, цена, линк, тегло за ротация
- `scenes` — кои от 8‑те anti‑boring сцени да ротира
- `copy.source` — `agent` (моделът пише българското заглавие, пазено от brand‑facts) или ръчно
- `offer`, `cta`, `link` — оферта/подкана/линк за описанието
- `publish.mode` — `approval` (препоръчано) или `auto`

## Структура на описанието (винаги еднаква)

Всеки пост има едно и също описание, като **само първият ред** се сменя:

```
<творческа реплика - единственото, което се генерира всеки път>

✅ Произведени в собствения ни цех в Пловдив, България
✅ 100% Памук с изключителна мекота и издръжливост
✅ Безплатна доставка с BOXNOW
✅ Онлайн сайт за поръчки
✅ Автентичен дизайн
✅ Безплатна замяна

<линк към ПРОДУКТОВАТА страница на тениската от поста>

При проблем или запитване, моля свържете се с нас на имейл: ullestorebg@gmail.com или на лично съобщение.
Поздрави от екипа на Юллѐ
```

Редактираш ползите/контакта/подписа в `config.json → caption_template`.
Линкът идва от `products[].product_url` (продуктовата страница, **не** landing page) - за ЩАСТИЕ SUMMER е `https://ulle.bg/products/tshirt-shtastie-summer`.

## Теми на постовете

Всеки пост е една от три теми:

| Тема | Кой я пише | Кога |
|---|---|---|
| **Продукт** | моделът (или резервният банк) — изчистен, сетивен текст за плата/кройката | авто, всеки ден |
| **Промо (evergreen)** | ротира офертите от `config.json → offers` + брандови истини | авто |
| **Анонс** | **ти**, в `announcements.json` | приоритетно, докато е активен |

**Важно за автономността:** ботът НИКОГА не измисля анонси (извинения, срокове, разпродажби). Тези факти идват само от `announcements.json`. Продуктовите и evergreen темите са безопасни за авто‑генериране, защото са стоящи истини.

### Как да пусна анонс

Отвори `announcements.json` и добави обект:
```json
{
  "text": "Извиняваме се за забавянето. Очаквайте пратките си до 2 дни.",
  "accent": "до 2 дни",
  "subhead": "Благодарим за търпението — Юлле",
  "badge": "Доставка",
  "cta": "",
  "start": "2026-09-05",
  "end": "2026-09-12"
}
```
- `accent` — думата/фразата, която се набива с Unbounded (трябва да се съдържа в `text`).
- `badge` — малкото етикетче горе (напр. „Доставка“, „Оферта“, „Важно“). Празно = без бадж.
- `start`/`end` — период, в който е активен (по избор). Докато е активен, има приоритет пред другите теми.
- `cta` — празно = без бутон.

### Чисти дни (само снимка + заглавие)

`config.json → post_style.clean_image_per_week` (по подразбиране **3**). Примерно толкова дни в седмицата постът е **само генерираната от OpenAI снимка**, без надпис върху картинката, а описанието е **само заглавието на поста**. Дните се избират автоматично и се въртят всяка седмица. Активен анонс има приоритет и отменя чист ден. Сложи `0`, за да ги изключиш.

### Оферти (промо ротация)

`config.json → offers` — списък от стоящи промоции. В момента:
```json
{ "headline": "Безплатна доставка с BoxNow.", "accent": "Безплатна доставка", "badge": "Доставка" },
{ "headline": "Вземи две, спести 20%.", "accent": "спести 20%", "badge": "Оферта" }
```
Добавяш/махаш оферти оттук; evergreen темата ги ротира.

## Как да пусна напълно автоматично (без одобрение)

Смени `publish.mode` на `"auto"` и `publish.auto` на `true` в `config.json`, добави Meta токени в `.env`. Тогава `run_daily` ще качва сам. **Препоръка:** остави го на `approval`, докато не се увериш в качеството.
